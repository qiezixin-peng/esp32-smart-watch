# ESP32 智能手表系统（T-Watch V3 + 传感器手环 + ThingsCloud 云平台 + 微信小程序）

一个**从硬件到云端到手机端全链路自研**的智能手表项目，功能覆盖：

**🖥️ 硬件端（两套固件）**
- **ESP32-C3 传感器手环**：BME280（温度/湿度/气压）+ MAX30102（心率/血氧）+ LTR390（紫外线），BLE 每 2 秒上报
- **T-Watch V3 手表**：6 款表盘 + 背景图融合显示（无黑框）、和风天气（3 日预报）、健康监测 + 心率/血氧阈值告警（本地震动 + 屏显）、BMA423 计步/活动识别、微信通知推送、闹钟/秒表/计时器、自动息屏 + 双击/抬手亮屏

**☁️ 云端（ThingsCloud 云平台）**
- MQTT 设备接入 + 属性上报（40s 周期）
- 异常告警属性即时上报（超阈值立即推送，不等周期）
- 下行通道：通知推送、表盘背景图下发（应用端 API）

**📱 手机端（微信小程序）**
- 实时数据首页（30s 刷新）
- 健康报表（折线图）/ 运动报表（24h 柱状图 + 7 天对比）
- 心率/血氧异常预警提示（同步告警状态）
- 表盘/背景图管理（上传即下发，3 槽保存）

```

│  · BME280 温湿压      │   每 2 秒     │   · 表盘/背景图/多款表盘    │
│  · MAX30102 心率血氧  │   JSON 数据    │   · 天气/健康/运动/通知     │
│  · LTR390 紫外线      │               │   · 闹钟/秒表/计时器        │
└────────────────────┘               └──────────┬───────────────┘
                                                 │ WiFi (NTP/MQTT)
                                                 ▼
                                      ┌──────────────────────┐
                                      │  ThingsCloud 云平台    │
                                      │  · MQTT 设备接入       │
                                      │  · 应用端 API          │
                                      └───────┬──────┬────────┘
                                              │      │
                              HTTP 属性上报     │      │ 下行(通知/背景图)
                                              ▼      ▼
┌────────────────────┐  云函数(定时/手动)   ┌──────────────────────┐
│  微信小程序          │ ─────────────────► │  微信云开发(云数据库)   │
│  · 实时数据首页      │                     │  health_records       │
│  · 健康报表(折线图)  │                     │  sport_report          │
│  · 运动报表(柱状图)  │                     └──────────────────────┘
│  · 表盘/背景图管理   │
└────────────────────┘
```

**通知链路（额外）**：手机微信来消息 → MacroDroid（无障碍监听）→ ThingsCloud 下行 MQTT → 手表震动+弹通知。

**健康告警链路**：手环实时采集心率/血氧 → 超阈值 → 手表本地震动 + 屏幕示警，同时经 ThingsCloud 即时上报 → 小程序端同步预警，做到"设备本地提醒 + 手机远程获知"双通道。

## 功能特性

### 手表端（T-Watch V3，ESP32 + PlatformIO）
- 🕐 **表盘系统**：6 款表盘（7段数码/Duo/点阵/简约居中/环形轨道/模拟）+ 背景图融合显示（文字直接"印"在背景上，无黑框）
- 🖼️ **背景图**：小程序上传，3 槽 FIFO 保存，左右滑切换、双击启用/停用
- 🌦️ **天气**：和风天气 API（当前 + 3 日预报），HTTPS + gzip 解压，内存不足自动降级
- ❤️ **健康**：温度/湿度/气压/心率/血氧/紫外线（来自 C3 手环 BLE）；心率/血氧超阈值（如 HR 过高/过低、SpO2 过低）时本地震动 + 屏幕示警
- 🏃 **运动**：BMA423 计步/活动检测/抬手亮屏（软件倾角 + 芯片中断双通道）
- ⏰ **时钟**：NTP 校时、闹钟（双击关闭）、秒表、计时器
- 🔔 **通知**：MQTT 下行实时推送微信通知
- 💤 **电源**：AXP202 管理、自动息屏、双击/抬手唤醒、低内存保护

### 小程序端（微信小程序 + 云开发）
- 实时数据首页（30s 轮询，不烧云配额）
- 心率/血氧异常预警：读取设备告警状态，超阈值时首页弹预警提示
- 健康报表：属性历史折线图
- 运动报表：今日总览 + 24 小时步数增量柱状图 + 最近 7 天对比（Canvas 2D 绘制）
- 表盘/背景图管理：上传图片当手表背景（MQTT 下发，base64 传输）

### 传感器手环端（ESP32-C3 SuperMini）
- BLE Server，每 2 秒采集三传感器 JSON 上报
- MAX30102 使用 Maxim 官方心率血氧算法 + 3 次中值平滑

## 技术栈

| 层 | 技术 |
|---|---|
| 硬件 | TTGO T-Watch V3、ESP32-C3 SuperMini、BME280、MAX30102、LTR390、BMA423 |
| 固件 | C/C++（Arduino 框架）、PlatformIO、TFT_eSPI、PubSubClient、ArduinoJson、BLE |
| 云端 | ThingsCloud（MQTT + 应用端 API）、和风天气 API、微信云开发（云函数 + 云数据库） |
| 小程序 | 微信小程序（WXML/WXSS/JS）、Canvas 2D 图表、云函数 Node.js |

## 快速开始

1. 准备硬件：T-Watch V3 + ESP32-C3 SuperMini + 3 传感器（见上）
2. 注册账号：ThingsCloud、和风天气、微信小程序（免费额度足够）
3. 按 [docs/DEPLOY.md](docs/DEPLOY.md) 分步配置并烧录

> 源码中所有真实凭据均已替换为占位符（`YOUR_*`），按部署文档填入自己的配置即可完整复刻。
